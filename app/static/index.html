如何获取 DeepSeek API Key

什么是 API Key？

API Key 相当于你的「AI 通行证」。本应用用它调用 DeepSeek 的大模型来生成回答，费用从你的 DeepSeek 账户余额里扣（每次问答约 1~2 分钱）。

获取步骤

  1. 打开 DeepSeek 开放平台：https://platform.deepseek.com（电脑浏览器，国内可直接访问）
  2. 点击右上角「注册 / 登录」，用手机号或邮箱完成注册
  3. 登录后，左侧菜单找到 「API Keys」，点击进入
  4. 点击 「创建 API Key」，随便填个名字（比如 gzr），点创建
  5. 创建后立刻 复制 那串以 sk- 开头的字符串（⚠️ 只显示这一次，务必先复制保存）
  6. （可选）在「费用」页 充值：新账号通常有赠送额度；用完再充，最低 ¥10 能用很久
  7. 回到本应用「设置」页，把复制的 Key 粘贴进输入框，点 「保存并测试连接」
  8. 显示「连接成功」后，去「问答」页提问即可 🎉

注意事项

  • Key 只保存在本机的 .env 文件里，不会上传到任何地方，请勿泄露给他人
  • 不配置 Key 也能用：问答页会显示「检索测试模式」，只能看到检索到的章节，没有 AI 回答
  • 官方价格与说明见 https://api-docs.deepseek.com
