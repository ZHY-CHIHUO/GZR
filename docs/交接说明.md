# 《蛊箓》项目开发交接说明（给接手 AI）

## 1. 项目是什么

本地运行的《蛊真人》小说知识库 Web 应用：问答（RAG）+ 阅读（原版txt/插图版PDF/人祖传/资料合集）+ 百科 + 游戏 + 设置。
技术栈：Python 3.13 + FastAPI + 单文件前端（无框架、无构建）+ 本地向量库 + DeepSeek API。

## 2. 启动方法

\`\`\`bash
cd gu-zhen-ren-rag
pip install -r requirements.txt
uvicorn app.main:app --port 8000
# 浏览器打开 http://localhost:8000
\`\`\`

## 4. ★ 连接 AI（DeepSeek）是怎么实现的

### 调用链路（一次问答的完整流程）

1. 前端 \`app/static/index.html\` 的 \`ask()\` 函数：用户点发送 → \`POST /api/ask\`，参数 \`{question, scope, history}\`
2. 后端 \`app/main.py\` 的 \`ask()\`：调 \`retriever.search(question)\` 检索相关片段（正文库+设定库，RRF 融合取 top-5）
3. \`app/rag.py\` 的 \`build_prompt()\`：把检索到的 5 个片段 + 问题拼成给 AI 的 prompt
4. \`app/rag.py\` 的 \`ask_llm()\`：用 openai SDK 调用 DeepSeek，拿到回答
5. 返回 \`{answer, sources, cost_rmb}\`，前端 \`mdRender()\` 渲染回答 + 来源卡片

### DeepSeek 调用的具体代码（app/rag.py 的 ask_llm）

\`\`\`python
def ask_llm(system, user, api_key, base_url, model, history=None):
    from openai import OpenAI
    client = OpenAI(api_key=api_key, base_url=base_url)  # base_url=https://api.deepseek.com
    messages = [{"role": "system", "content": system}]
    for h in (history or [])[-8:]:  # 多轮追问上下文
        messages.append({"role": h["role"], "content": h["content"]})
    messages.append({"role": "user", "content": user})
    resp = client.chat.completions.create(model=model, messages=messages, temperature=0.4, max_tokens=1024)
    return resp.choices[0].message.content or ""
\`\`\`

### API Key 从哪来

- \`app/config.py\`：启动时从项目根目录 \`.env\` 文件读 \`DEEPSEEK_API_KEY\`（还有 \`DEEPSEEK_BASE_URL=https://api.deepseek.com\`、\`DEEPSEEK_MODEL=deepseek-chat\`）
- 网页「设置」页可粘贴 Key → \`POST /api/settings\` → \`config.set_api_key()\` 写回 \`.env\`，无需重启
- **没有 Key 时**：\`/api/ask\` 返回 mock 结果（只显示检索到的来源，不调 AI），前端显示“测试模式”提示
- 模型默认 \`deepseek-chat\`（可换 \`deepseek-v4-flash\` / \`deepseek-v4-pro\`）

### 检索（prompt 里喂什么）

- 混合检索：BGE-M3 稠密向量 top-20 + BM25 关键词 top-20 → RRF 融合 → 取前 5 个片段
- 每个片段：章节标题 + 正文前 600 字
- 正文片段带「第N卷·第N章·标题」标签，prompt 要求 AI 利用章节标题回答「首次出现」类问题

## 5. 前端 UI 修改注意事项

- **全部 UI 在 \`app/static/index.html\`**：\`<style>\` 在头部，\`<script>\` 在尾部，改完浏览器 Ctrl+F5 刷新即生效（无需重启服务）
- 无任何前端框架/CDN 依赖（仅本地 pdfjs），保持零构建
- 5 个 tab：问答 / 阅读 / 百科 / 游戏 / 设置，对应 \`<section id="tab-*">\`
- 阅读区的三套目录（原版/插图版/资料合集）都用 \`<details>\` 折叠树，交互已统一
- PDF 阅读用 PDF.js canvas 渲染（\`renderChapter()\`），章节内连续滚动 + 上一章/下一章
- 主题色变量在 \`:root\`（--bg / --card / --accent / --accent2 等）

## 6. 不要动的东西

- \`data/\`、\`data_jina2/\`：预建向量库和缓存数据，改 UI 不需要动
- 原始小说文件在项目**外**一层（\`../gu-zhen-ren\` txt、\`../gu_zhen_ren_pdf\` PDF、\`../gu-zhenren-lore\` docx），阅读功能实时读它们；只优化 UI 不需要碰
- \`.env\`：含用户 API Key，不要提交/不要写死
