# 百科数据 v2：树结构存储

## 存储结构（data_jina2/wiki.json）

嵌套树：**分类 → 分组 → 词条**，词条节点必含 "name" 字段。

```json
{
  "蛊虫": {
    "一转": {
      "酒虫": {
        "name": "酒虫",
        "desc": "以酒水为食物，能够凌空飞行。……",
        "sub": "一转",
        "section": "蛊一转蛊虫",
        "source_path": "蛊虫百科 / 蛊一转蛊虫"
      },
      "月光蛊": { "name": "月光蛊", "desc": "……", "sub": "一转" }
    },
    "二转": { "…": {} }
  },
  "荒兽荒植": {
    "太古荒兽": {
      "九尾狐": { "name": "九尾狐", "tier": "太古荒兽", "desc": "太古荒兽，记载于《人祖传》。" }
    }
  },
  "人物": {
    "八转蛊仙": { "血海老祖": { "name": "血海老祖", "desc": "……" } }
  },
  "_deleted": [ ]
}
```

## 规则

- 蛊虫按来源小节“蛊X转蛊虫”推导分组（一转/二转…），并清理词条名前导括号标注（如“（凡蛊单一）酒虫”→“酒虫”）。
- 荒兽荒植按 tier 分组；人物/境界流派等按 sub 分组；其余分类词条直接挂在分类下。
- 分组节点不含 "name" 字段；词条节点必含 "name"。

## API

/api/wiki 同时返回：
- categories：展平数组（旧前端兼容），词条 sub=父分组名
- tree：树结构（新前端/未来使用）
- stats：分类计数

## 后端适配

- main.py 用 _iter_wiki_entries 递归遍历树；wiki_update 支持树定位（新增/编辑/移动/删除/回收站）。
- build_wiki_store.py / build_quiz.py 递归遍历树生成索引与题库。
- 旧 wiki_flat_backup.json 保留扁平快照，可回退。
