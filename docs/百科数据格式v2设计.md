# 百科数据格式 v2 设计说明

## 文件布局

```text
data_jina2/
├── wiki.json           # 词条数据（v2 结构化字段）
├── wiki_schema.json    # 分类顺序、显示标签、分级体系（新增）
└── wiki/               # RAG 索引（meta.json + vectors.npy，由脚本生成）
```

## 词条字段（v2）

| 字段 | 说明 |
|---|---|
| name | 正式名称 |
| aliases | 别名数组（搜索/问答可命中） |
| cat | 一级分类（作品资料/作品设定/人物/蛊虫/仙蛊屋/荒兽荒植…） |
| sub | 细分（蛊虫转数、人物修为等） |
| tier | 该分类分级轴上的级别（如 太古荒兽、太古荒植） |
| intro | 一级介绍：一句话摘要（列表与 RAG 摘要用） |
| sections | 二级介绍：分主题数组 [{title, text}]（详情页分节渲染） |
| desc | 旧版纯文本，保留兼容；新词条可省略 |
| section | 原始来源小节 |
| source_path | 按校对目录计算的分级路径 |

示例：

```json
{
  "name": "九尾狐",
  "cat": "荒兽荒植",
  "sub": "太古荒兽",
  "tier": "太古荒兽",
  "intro": "太古荒兽，记载于《人祖传》。",
  "section": "蛊界资料之太古荒兽篇",
  "source_path": "荒兽荒植等生物 / 蛊界资料之太古荒兽篇"
}
```

## 分级体系（wiki_schema.json）

每类可定义独立的等级轴（类似生物分级）：

```json
{
  "taxonomies": {
    "荒兽荒植": {
      "levels": ["普通野兽","百兽王","千兽王","万兽王","兽皇","荒兽","上古荒兽","太古荒兽","太古传奇荒兽"],
      "meta": { "对应转数": ["普通","二转","三转","四转","五转","六转","七转","八转","八转巅峰及以上"] }
    },
    "蛊虫": { "levels": ["一转","二转","三转","四转","五转","六转","七转","八转","九转","十转","仙蛊","其他"] },
    "人物": { "levels": ["凡人","蛊师","六转蛊仙","七转蛊仙","八转蛊仙","九转蛊尊","尊者","其他"] }
  }
}
```

## 展示与检索规则

- 列表卡片：name + tier 徽章 + intro
- 详情页：intro 为导语，sections 逐节渲染（二级介绍），aliases 展示别名，tier 显示“级别”
- 搜索：匹配 name / aliases / intro / sections / desc
- RAG 索引文本：`name：intro+各节正文（别名：xx）【tier】`，检索与摘要更精准
- 同一实体可在不同分类各有一条（如九尾狐在“蛊虫”为引用条目、在“荒兽荒植”为本体条目），按 cat 内 tier 分级，互不冲突
