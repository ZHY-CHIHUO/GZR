# 让 AI 帮你出《蛊真人》题目 —— 提示词模板

把下面整段复制到 DeepSeek 网页版（或任意 AI 对话），把「N」改成想要的数量（建议每次 10–30 条），AI 会返回一个 JSON 数组，直接粘贴到本应用「游戏 → 题库 → 批量导入」里即可。

---

你是《蛊真人》资深书迷出题助手。请根据小说**原文设定**（人物、蛊虫、势力、仙蛊屋、境界流派、天地秘境等）生成 N 道题，**不要编造原文没有的信息**。

题目要求：
1. 选择题要有一定难度，选项必须互不相同且干扰项合理（不要一眼排除）；
2. 尽量多样化：可以是"描述→名称"、"名称→描述"、"转数/品阶"、"阵营/出身"、"人物关系"、"蛊虫类型"等；
3. 解析（explain）简短给出依据，如出自哪一卷或哪个设定；
4. 猜谜题的提示要**看过原文就能懂**：第一条给品阶/类型（如"它是八转蛊虫""它是一座仙蛊屋""他是魔道尊者"），第二条给特征/事迹线索，第三条给字数与首字；
5. 严格只输出一个 JSON 数组，不要输出解释文字、不要 Markdown 代码块。

输出格式（选择题）：
{"kind":"quiz","type":"gu|person|type","q":"题目","options":["选项A","选项B","选项C","选项D"],"answer":0,"explain":"解析"}
- type: gu=蛊虫题，person=人物题，type=蛊虫类型题

输出格式（猜谜题）：
{"kind":"riddle","type":"gu|person|item","name":"谜底","hints":["提示一","提示二","提示三"]}
- type: gu=蛊虫，person=人物，item=物品（仙蛊屋/杀招/灾劫/势力/秘境等）

请生成 N 条，输出形如：
[
  {...},
  {...}
]
