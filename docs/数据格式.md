# 数据格式说明（资料库 & 题库）

本应用的所有百科与游戏数据都是**纯 JSON 文件**，可直接用文本编辑器（VS Code 等，务必 UTF-8 编码）修改，也可交给 AI 对照本说明批量修改。

## 二、资料库 wiki.json 格式

顶层结构是「**分类名 → 条目数组**」：

    {
      "人物": [
        {
          "name": "血海老祖",
          "desc": "血道蛊仙，血道开创者，巨阳仙尊的分身。……【第三百七十四节:收取西漠僵盟遗藏】",
          "section": "七转蛊仙",
          "sub": "其他"
        }
      ],
      "蛊虫": [ ... ],
      "仙蛊屋": [ ... ]
    }

每条目字段：
- **name**（必填）：条目名称，如"方源""春秋蝉""天庭"；
- **desc**（必填）：条目正文。可含换行；引用原文时保留 `【第X节:标题】` 这种格式；
- **section**：来源章节/设定名，如"蛊八转蛊虫"、"天地秘境"；
- **sub**：细分标签。蛊虫用 "一转"~"九转"/"仙蛊"/"其他"；其他分类可留空字符串。

现有分类（顶层 key）：
`作品资料`、`世界设定`、`天地秘境`、`五域地理`、`人物`、`蛊虫`、`势力`、`仙蛊屋`、`杀招`、`灾劫`、`境界流派`、`人祖传`、`其他`

> 注意：`其他` 里的条目前端会按 section 关键词**自动归类**到上面这些新分类；手工新增条目建议直接放进正确分类，不要放"其他"。

## 三、题库 quiz.json 格式

顶层两个字段：`quiz`（选择题数组）与 `riddles`（猜谜池）。

    {
      "quiz": [
        {
          "type": "蛊虫",
          "q": "以下哪个蛊虫符合这段描述：不完美的至尊仙胎蛊，有弊端。……",
          "options": ["宝蓝狸", "至尊仙胎蛊", "年蛊", "锦绣食盒蛊"],
          "answer": 1,
          "explain": "至尊仙胎蛊：不完美的至尊仙胎蛊，有弊端。……"
        }
      ],
      "riddles": {
        "gu": [
          {
            "name": "至尊仙胎蛊",
            "options": ["幻影月蛊", "至尊仙胎蛊", "雷电蛊便道", "金汤蛊"],
            "hints": ["它是九转蛊虫", "线索：……", "相关角色：……", "出处：第三百七十四节:……", "它的名字共 5 个字，首字是「至」"]
          }
        ],
        "person": [ ... ],
        "item": [ ... ]
      }
    }

### quiz 元素（选择题）
- **type**：`"蛊虫"` | `"人物"` | `"蛊虫类型"`（决定答题页里"蛊虫题/人物题/蛊虫类型题"的筛选）；
- **q**：题目文字；
- **options**：**正好 4 个**选项字符串；
- **answer**：正确选项下标，0~3；
- **explain**：答案解析。

### riddles 元素（猜谜）
- **name**：谜底名称；
- **options**：4 个选项（当前猜谜界面是纯手动输入，此字段暂不使用，保留兼容）；
- **hints**：提示数组，**5~10 条**。规范：第一条给品阶/类型（如"它是八转蛊虫""它是一座仙蛊屋""他是魔道尊者"），中间给线索/相关角色/出处章节，最后一条给名字字数与首字。

## 四、前端自定义题库格式（AI 出题 / 批量导入用）

在「游戏 → 题库 → 批量导入」粘贴的 JSON 数组，每项两种：

选择题：
    {"kind":"quiz","type":"gu|person|type","q":"题目","options":["A","B","C","D"],"answer":0,"explain":"解析"}

猜谜题：
    {"kind":"riddle","type":"gu|person|item","name":"谜底","hints":["提示一","提示二","提示三","提示四","提示五"]}

> 出题提示词模板见 `docs/AI出题提示词.md`。

## 五、修改流程建议

1. 用 **UTF-8** 打开 `data_jina2/wiki.json`（和 `data/wiki.json` 一起改，保持两份一致）；
2. 只改字段值、不要改 JSON 结构；改完用 JSON 校验工具检查逗号/引号；
3. 刷新页面即可在百科看到修改（服务自动热加载）；
4. 想让**选择题/猜谜**也用上新资料：在百科编辑弹窗点「重建游戏题库」，或运行：
       .venv\Scripts\python.exe scripts\build_quiz.py
       Copy-Item data_jina2\quiz.json data\quiz.json -Force
5. 如果改乱了，可用 git 恢复：`git checkout HEAD -- data/wiki.json data_jina2/wiki.json`。
