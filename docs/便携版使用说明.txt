【蛊箓 · 蛊真人维基百科 便携版 v1.1.0】

1. 将整个文件夹解压到任意可写位置。
2. 双击 gu-zhen-ren-rag 文件夹中的「一键启动.bat」。
3. 等待服务启动后，浏览器会自动打开 http://127.0.0.1:8000。

本包已内置：
- 独立 Python 运行时与全部依赖；
- Jina 中文向量模型和已建立的向量索引；
- 百科、题库、小说全文、资料合集与插图 PDF。

因此百科浏览、阅读、游戏和本地检索不需要安装 Python，也不需要首次下载模型。GPU 不是必需条件。

AI 问答与联网搜索：
- 本地检索不需要 API Key；
- 想让外部 AI 生成回答时，在网页「设置」中填写自己的 Base URL、API Key 和模型名；
- 本包不会携带制作者的 API Key 或其他个人配置。

编辑资料后：
- 百科编辑会立即显示；
- 为让新词条参与语义检索，请进入「设置」→「检索模型」，点击「重建百科索引」；
- 重建不会修改百科正文，完成后会自动刷新检索器。

资料分享：
- 「设置」→「资料包」可导出、导入或完整备份资料；
- 导入前会先显示文件清单和冲突预览；
- 合并导入保留本地冲突，覆盖导入会自动备份。

建议在 Windows 10/11 64 位系统运行，并预留至少 2 GB 可用磁盘空间。请勿公开传播本包中的原著全文与受版权保护资料。
